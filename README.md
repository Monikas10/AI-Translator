# AI-Powered Multi-Language Translator

## 📌 Project Description
AI-Powered Multi-Language Translator is a web-based application that translates text from one language to another using Artificial Intelligence. It also allows users to select different tones for the translated output.

## 🚀 Features

- 🌐 Multi-language text translation
- 🎯 Multiple tone options
- 🤖 AI-powered translation
- 📋 Copy translated result with one click
- 📥 Download translated results
- 💻 Simple and user-friendly interface
- ⚡ Fast translation

## 🛠️ Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- LangChain
- Google Gemini AI

## 🎨 Available Tones
- Formal
- Casual / Friendly
- Poetic
- Professional / Business
- Humorous

## ⚙️ How to Run

1. Clone this repository.
2. Install the required Python packages.
3. Add your Gemini API key in the `.env` file.
4. Run the Flask application.
5. Open the application in your web browser.

## 🔐 Environment Variables

Create a `.env` file and add:

GEMINI_API_KEY=your_api_key_here

⚠️ Do not upload your `.env` file or expose your API key publicly.

## 🎯 Purpose
The main goal of this project is to provide an easy and intelligent translation experience using Generative AI.
